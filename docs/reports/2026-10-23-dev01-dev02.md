## DEV-02 结果

ADR 固定 `space_id` / 显式 `SpaceContext`、频道内独立文章、自然键范围及复合外键，保留旧单站/旧 URL 的明确默认频道适配。设计包含数据影响矩阵、版本与任务恢复、配置/缓存、报告/通知/预算，以及分阶段迁移、回填和回退边界。

原型独立类型检查通过，真实 PostgreSQL **6 / 6 测试通过**：

1. 拒绝缺失、非本地、非测试库和带连接参数覆盖的地址。
2. 同 URL 在频道内去重、跨频道生成独立结果，一边 BLOCK 不改变另一边选中状态。
3. 规则/配置或输入修订产生新的逻辑请求，并保留历史结果。
4. 绕过业务函数直接写入的跨频道引用被真实外键拒绝。
5. 两频道同日各出一份简化报告，分别进入自身通知目标，重放不重复建投递记录。
6. 未知频道/配置版本不能回落到其他频道。

每个数据库用例使用事务内随机 schema，成功/失败均回滚，成功后确认 schema 无残留。规则为本地确定性夹具，通知仅写入 pending 记录；没有调用真实模型或消息服务。原型没有证明现有 publication、采集、模型回执、缓存、预算或生产迁移已经完成频道改造。

重要迁移结论：同频道自然键变为 `(space_id, identity_key)` / `(space_id, kind, key)`；全局业务 ID 保留。第二频道写入之后，不能直接回退到未支持频道范围的旧镜像。频道编辑独立，但原发布者的撤回/许可失效应联动各频道副本。
