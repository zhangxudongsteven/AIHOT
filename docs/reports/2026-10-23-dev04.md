# DEV-04：统一网站频道切换与公开出口隔离

日期：2026-10-23（Asia/Shanghai）。状态：DEV-04 已完成本地验收；不代表 GKE 部署或业务上线。

## 交付

- 桌面侧栏和手机入口增加频道切换。切换进入目标频道首页，文章/事件 ID、筛选和上一频道的内容状态不会随切换带过去；浏览器后退保留原频道地址。
- `/channels/:slug` 下复用现有文章、事件、专题、热点、搜索、收藏、Agent 和公共页面。分类、词表及公开名称读取频道活动配置，共享网站品牌及法律模板保持原样。
- 网站 API、v1、RSS、Agent Markdown、MCP、OG、sitemap、llms 和 OpenAPI 使用同一 publication 读取上下文。未知或停用频道拒绝读取，异频道对象返回 404；畸形频道 URL 不回落默认频道。
- 旧 URL 固定读取默认频道的活动配置，保留默认数据及链接兼容。频道选择不通过 Cookie 或可变进程全局变量改变匿名响应。
- 查询/搜索/热点/主题/站点地图缓存、ETag、列表游标、MCP 工具和响应缓存绑定频道。浏览器收藏、已读、搜索历史、反馈草稿、预览及页面缓存各自隔离；外观和字体共享。
- 精选 ledger/state 写入频道，保留全局提交顺序；snapshot、changes、epoch、水位和分页按频道读取。旧无频道同步游标仅默认频道接受，跨频道同步游标返回 409。

针对性行为覆盖：

1. 两频道并发使用相同查询，网站 API、v1、RSS、Markdown、MCP、OG、sitemap 不混入其他频道或默认频道的记录。
2. 详情、原文、事件、可用性、热点、摘要引用和分享出口核验对象归属；非默认频道不借用默认报告或共享引用译文。
3. 同步快照分页、交错更新、撤回、删除后 tombstone 和旧游标兼容；移除记录不会暴露其他频道的 ID。
4. 默认配置更新后的动态分类（实际发布的自定义分类在列表和同步快照均保留）、频道停用后的新请求、条件请求、HTTP 方法、错误协议和缓存验证。
5. 桌面/手机切换、页面刷新及后退、筛选、搜索、收藏、分享、反馈草稿延迟保存、未知频道和畸形 URL。
