- **GEPA-Curator：Agent 学习经验筛选**：在提示优化前筛选可靠任务，并检索过去的成功轨迹，减少噪声失败样本干扰。作者在多类 Agent 任务中报告效果改善，本轮未核验实验。

- **MuonGS：预训练优化器的范数控制**：通过 Gram–Schmidt 投影去除更新的径向分量，放松固定权重范数约束。作者给出理论分析，并在小规模模型预训练中报告困惑度改善。
- **CrossProfile：多 Agent 记忆与群体决策**：构造可控评测，检验群体讨论记忆中的信息选择。摘要指出，仅保留相关或稀有信息可能留下诱导证据，信息的多人归属还可能引入从众偏差。
