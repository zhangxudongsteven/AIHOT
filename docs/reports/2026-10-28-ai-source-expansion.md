# AI 频道信源补充方案与采集验证

日期：2026-10-28（北京时间）。本阶段状态：供人工审阅，未导入、未启用、未部署。

本文保留补源方案阶段的观察；后续验证与启用记录见[当日运营汇总](2026-10-28-operations-summary.md)。

## 方案阶段快照与目标

方案阶段只读核验正式环境：AI/default 频道仅有 a16z News，T2、每 60 分钟采集，频道与采集/模型开关开启。10 月 28 日 13:49 的快照为近 24 小时采集 22 次、失败 0 次、新增 4 篇、全部动态 eligible 3 篇、精选 0 篇。来源昨天才创建，尚不足以推断长期产出率。

目标是补足国内外一手发布、研究进展、独立编辑报道与工程观察，降低单一投资机构视角。以下优先级是建议，由使用者最终决定采信名单；不改变既有评分权重、门槛或分类。

## 验证方法和边界

- 从正式 API 容器的实际网络发出免费公开 GET；使用项目现有 `fetchRss`、`fetchWebList`、`assertSupportedConfig` 和 `extractFromUrl(..., {paidFallback:false})`。
- RSS 核验标题、独立链接和可解析日期；网页列表实际配置选择器后运行解析器；每个深入验证的来源检查前两条正文，订阅/章节已带正文时直接记录其长度。
- 只调用读取函数，没有调用 collect、预览管理接口、入库、队列、模型、Jina 付费兜底、推送或来源 apply。没有修改运行环境的开关。
- 计数是当次列表/订阅包含的条目数，不是日增量或保证的历史覆盖。正文“2/2”只证明两条样本能取得非空正文，未逐段核对完整性，也不代表所有历史页面可读。
- 没有执行模型筛选、入选质量评测、事件去重、发布验收或持续稳定性测试。采集可行不等于全文再分发许可；后续候选均建议关闭 `site_fulltext`、`syndicate_fulltext`。
- 中文无时区日历日期按 +08:00；Anthropic 列表只给日期，按 +00:00 的日期精度记录，与正文元数据样本一致，不声称准确发布时间或擅自固定美国夏令时。

可复核的端点、配置、样本链接、日期和正文长度见 [验证证据 JSON](evidence/2026-10-28-ai-source-probes.json)。它是报告附件，不是可直接 apply 的来源导入文件；其中 `enabled:false` 表示候选意图，未保存到后台。

## 后续建议：先验证质量，再由使用者决定启用

1. 人工确认首批名单及希望关注的内容类型、噪声边界；本方案不代替采信决定。
2. 在独立验证环境准备禁用候选；保留首次回灌限制，建议初始取 3～5 条，并沿用原文时间归档。OpenAI 这类大订阅尤其不能直接导入全部历史。
3. 逐源检查若干样本的原始标题、日期、正文有效性与筛选结果；区分相关性拦截、低分、历史回灌和处理错误。不能为增加入选数量随意降低门槛；需要修改门槛时使用用户标注样本校准。
4. 获得启用指令后，分两批小量放行，并观察 3～7 天的新增量、采集失败、正文成功、eligible、selected、重复事件及模型请求成本。本阶段不能给出可靠日均文章量或成本预测。
5. 对 Google 同集团、多媒体转载和商业稿保留发布方身份，沿用公共读取层与现有归组，不新增公开出口或绕过预算回执。

本次只新增本地方案和脱敏验证证据文件；没有写入后台来源、改变 AI/security 频道配置、启停服务或执行真实内容流水线。
