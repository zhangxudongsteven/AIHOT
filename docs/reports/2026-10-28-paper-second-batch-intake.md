## 定向范围与数量

- cs.LG 要求标题体现训练、预训练、后训练、微调、优化器或优化，并在标题/摘要中关联 LLM 或语言模型。
- cs.CV 围绕视觉语言模型、VLA、多模态大模型、视频/图像生成、视觉推理，以及关联这些模型的评测；不使用泛 Agent 或独立 LLM 关键词覆盖整个分类。
- 使用官方查询 API 的 Atom 输出，按原始 submittedDate 倒序，每次读取最新 100 条。正式创建前实测：固定起点之后，cs.LG 有 15 条、cs.CV 有 27 条，当次起点范围未被 100 条窗口截断；不将此结果当作长期完整分页保证。
- 首次回灌每源最多 3 条、最近 1 个月；publishedAfter 固定为 2026-10-26T00:00:00.000Z，沿用已有论文试运行的历史边界。原文首版日期、版本更新时间由 API 读取，不用订阅更新日冒充首版时间。
- 六篇首次导入资料均为回灌，摘要网页已读取；没有读取论文全文或验收实验。站内全文及全文分发均关闭，未开启 summaryIsBody。
- 现有 URL 身份可合并同版本跨来源条目，arXiv 不同 v1/v2 尚无专门去版本归一；仍需观察跨版本重复。新版本不应被描述成首次发表。

## ACL 为何未开启

- 官网可访问，但正式部署网络读取 /events/emnlp-2026/ 与 /events/acl-2026/ 均超时，逐篇目录在当次尚未通过采集器验证。
- 官方论文页样本 2026.emnlp-main.1 只列 October 2026，2026.acl-long.1 只列 July 2026，没有核验到具体发布日期。月份不能补成某日，也不能把 Git 提交日、抓取日或会议日期直接当作单篇发表时间。
- 因此 ACL 当时只以禁用 external 入口登记，名称和标签注明待接入；没有伪造 RSS 地址或启用一个未工作的网页采集器。该入口在登记期间不执行自动采集，不代表已经具备 ACL/EMNLP 全量论文覆盖。
- 官方建议从仓库元数据或其 Python 模块读取论文信息。后续需要完成元数据增量导入与日期精度/归档方式，再验收和启用。未安装依赖、修改核心日期规则或为了接入降低日期可信要求。

官方依据：[ACL 数据访问说明](https://aclanthology.org/faq/api/)、[EMNLP 样本](https://aclanthology.org/2026.emnlp-main.1/)、[ACL 样本](https://aclanthology.org/2026.acl-long.1/)。
