## 实现范围

| 范围 | 结果 |
| --- | --- |
| 报告 | 同一日期的日/周/月报按频道独立生成、归档、去重、补刊与更正；报告和旧修订记录配置版本；日报不调用模型 |
| 调度与告警 | 报告和翻译按启用频道运行，一频道失败不阻止其他频道；日报缺失告警独立发现/恢复/过期 |
| 配置与并发 | 快照保存报告时间、空刊文案和行业指标；旧配置晚到不能覆盖新报告或译文，仍保留并完成对应付费回执 |
| 公开出口 | 网站日报/周报/月报与归档、API、RSS、Agent Markdown、MCP、OG、llms/sitemap 均保持频道范围；读取不调用模型 |
| 推送 | 各频道独立目标、订阅、去重租约、投递记录和重发范围；新报告保存与通知入队同事务，显式更正不自动重推 |
| 兼容与恢复 | 原目标只订阅精选，报告需显式订阅；新频道默认目标禁用且无凭证引用；unknown 不自动重发；禁用频道可做不外发的人工对账 |
| 配额 | 平台总预算与频道预算共同约束，每分钟/小时/24小时滚动计数；支持显式保留容量，并发不能超卖；失败、unknown、重试和 fallback 均计 attempt |
| 翻译 | 本文和引用帖都使用频道模型、提示词与回执；同一引用帖在不同频道独立存储；配置变更后重译，来源自带中文保留 |
| 管理 | 管理 API 和 `scripts/space-ops.ts` 可配置及读回目标/订阅/预算；写入与审计同事务，管理站可看到频道/订阅并启停目标 |
